# Настройка Apache для 1c-batch

Используйте файлы из `src/apache-proxy/`: `configure-apache.cmd` и лежащий рядом
`httpd-batch-proxy.conf`. Дополнительные программы устанавливать не нужно.
Тестировалась 2.4.66

## Внести изменения

1. Запустите **configure-apache.cmd** от имени администратора.
2. Выберите **1 — внести настройки**.
3. Укажите папку установки Apache, например `C:\Apache24`. Для этого пути достаточно Enter.
4. Дождитесь сообщения об успешной записи настроек.
5. Перезапустите службу Apache через окно **«Службы» Windows**. На этом компьютере она называется `Apache2.4`.

Скрипт проверит конфигурацию, сохранит резервную копию и внесёт изменения.
При ошибке после начала изменений исходные файлы будут восстановлены автоматически.
Маршрут: `http://localhost/batch/` → `http://127.0.0.1:8765/`.

## Какие файлы затрагиваются

Пути указаны относительно выбранной папки Apache:

| Файл | Изменение |
|---|---|
| `conf/httpd.conf` | Добавляется подключение настроек, если его ещё нет |
| `conf/extra/httpd-batch-proxy.conf` | Создаётся или заменяется файл настроек `/batch/` |
| `conf/1c-batch-backups/<дата-время-код>/` | Сохраняются исходные файлы и сведения для восстановления |

Если файл настроек уже существовал, он тоже попадёт в резервную копию.
После перезапуска Apache будет писать обращения к `/batch/` в `logs/batch_access.log`.

Фрагмент загружает `proxy`, `proxy_http` и `rewrite`, если они ещё не загружены.
Для `/batch/` запрос с `Content-Length` больше 32 МиБ отклоняется Apache с HTTP 413.
Без `Content-Length` размер контролирует сам исполнитель при чтении тела;
одного `LimitRequestBody` недостаточно для проверенного режима проксирования.

## Восстановить исходные файлы

1. Запустите **тот же configure-apache.cmd** от имени администратора.
2. Выберите **2 — восстановить файлы**.
3. Укажите ту же папку Apache.
4. Выберите резервную копию: **1 — последняя**, остальные показаны в списке.
5. После успешного восстановления перезапустите службу Apache через **«Службы» Windows**.

Будут восстановлены `conf/httpd.conf` и прежний файл настроек `/batch/`.
Если до установки этого файла не было, скрипт удалит созданный фрагмент.
Текущее состояние перед восстановлением сохраняется в подпапке `before-restore`
выбранной резервной копии. Журналы Apache не удаляются.

**0 в меню — выход без изменений.** Сам скрипт службу Apache не перезапускает.
