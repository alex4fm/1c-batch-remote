# Ручная настройка Apache для 1c-batch

Пример ниже рассчитан на Apache 2.4 в `C:\Apache24`. Если Apache установлен в другом каталоге, замените этот путь на свой. Исполнитель 1c-batch должен работать на том же компьютере и принимать запросы по адресу `127.0.0.1:8765`.

1. Сохраните резервную копию `C:\Apache24\conf\httpd.conf`.

2. Скопируйте находящийся рядом с этой инструкцией файл `httpd-batch-proxy.conf` в каталог `C:\Apache24\conf\extra\`. Полный путь к копии:

   ```text
   C:\Apache24\conf\extra\httpd-batch-proxy.conf
   ```

3. В основном файле `C:\Apache24\conf\httpd.conf` добавьте на уровне сервера, после существующих директив `LoadModule` и вне блоков `<VirtualHost>`, следующую запись:

   ```apache
   # BEGIN 1c-batch proxy
   Include "conf/extra/httpd-batch-proxy.conf"
   # END 1c-batch proxy
   ```

   Путь в `Include` отсчитывается от `ServerRoot` Apache. Подключайте файл только один раз: если он уже входит через существующий `Include` с шаблоном, добавлять вторую запись не нужно. Проверьте также, что существующие правила и виртуальные хосты не перехватывают маршрут `/batch/`.

4. Проверьте наличие модулей `mod_proxy`, `mod_proxy_http` и `mod_rewrite` в каталоге `modules`. Фрагмент сам загружает их, если они ещё не загружены. Также должны быть доступны модули `authz_core`, `log_config` и `setenvif`. При ошибке загрузки проверьте установку модулей и сообщения проверки конфигурации.

5. В командной строке проверьте конфигурацию и список подключённых файлов:

   ```cmd
   C:\Apache24\bin\httpd.exe -t
   C:\Apache24\bin\httpd.exe -t -D DUMP_INCLUDES
   ```

   Первая команда должна сообщить `Syntax OK`, а в списке второй должен быть `httpd-batch-proxy.conf` один раз. Если проверка не прошла, исправьте указанную ошибку или восстановите резервные копии; не перезапускайте Apache с ошибочной конфигурацией.

6. Перезапустите свою службу Apache через «Службы» Windows. Запустите исполнитель и проверьте его API через Apache, например `http://localhost/batch/v1/probe`. Запрос без токена может вернуть `401`, если авторизация включена: это подтверждает, что запрос дошёл до исполнителя. Для полноценной проверки используйте клиент и действующий токен. Если Apache слушает другой адрес или порт, подставьте их вместо `localhost`.

Маршрут `/batch/` направляется на `http://127.0.0.1:8765/`; при другом адресе исполнителя измените адреса в директивах `ProxyPass` и `ProxyPassReverse` в скопированном файле и снова проверьте конфигурацию. Фрагмент ограничивает известный `Content-Length` до 32 МиБ; тела без него ограничивает исполнитель. Отдельный журнал запросов находится в `C:\Apache24\logs\batch_access.log` относительно `ServerRoot`.

Для отката восстановите сохранённый `httpd.conf` и прежний файл прокси, если он существовал; иначе удалите добавленный файл прокси. Проверьте конфигурацию командой `httpd.exe -t` и перезапустите службу.
